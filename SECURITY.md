# Security policy

Report vulnerabilities privately to the repository maintainer via GitHub's private vulnerability reporting feature, if enabled; otherwise open a security issue without exposing exploit details and request a private contact method. Do not include sensitive saved archives in public reports.

Capture is on-demand. No persistent host permissions and no remotely loaded extension code. Resource fetches use browser fetch; saved HTML scripts are removed, but **MHTML archives are untrusted documents** and must be opened with care. Complex resources may be incomplete. No known security review or production browser certification has been performed for this release.
